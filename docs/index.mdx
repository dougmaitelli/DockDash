## Discover and monitor every service

Bring Docker containers, Kubernetes workloads, network services, and manually added endpoints into one inventory. DockDash keeps their live state and recent behavior visible from the same dashboard.

<CardGrid>
  <Card title="Service discovery" icon="magnifier">
    Scan local or remote Docker hosts, selected Kubernetes clusters and namespaces, and configurable
    network ranges.
  </Card>
  <Card title="Interactive topology" icon="code-branch">
    Arrange services on a shared canvas, group related workloads, and draw labeled relationships.
  </Card>
  <Card title="Health and uptime" icon="heart">
    Track live service status and review health history across the last 1, 7, or 30 days.
  </Card>
  <Card title="Resource history" icon="clock">
    Follow current and historical CPU and memory usage, plus Docker network and disk activity.
  </Card>
</CardGrid>

## Know what actually changed

DockDash understands version-shaped image tags. Instead of only reporting that a digest changed, it can tell you that a pinned service can move from **1.25 to 1.26**, then place the matching release notes beside the update.

<CardGrid>
  <Card title="Version-aware updates" icon="rocket">
    Compare compatible registry tags while preserving prefixes and suffixes such as `v`, `release-`,
    and `-alpine`.
  </Card>
  <Card title="Changelogs" icon="notes">
    Resolve the source repository and place the matching GitHub release notes beside the available
    version.
  </Card>
  <Card title="Notifications" icon="email">
    Send the running and available versions through [Apprise](https://github.com/caronc/apprise-api)
    instead of a generic image-change alert.
  </Card>
</CardGrid>
